# Digital Solutions for Insurance Services

A simple front-end prototype: browse plans, calculate premiums, buy policies, file claims and view a dashboard.

## Run
Open `index.html` in any web browser. No installation needed.

## Files
- index.html - page structure
- style.css  - styling (light/dark theme)
- script.js  - plans, premium formula, policies, claims, dashboard (data saved in browser localStorage)
